TST15 Homepage Starter
=====================
Open index.html in a browser to preview locally.

Files:
- index.html: page structure
- styles.css: responsive design and layout
- script.js: mobile navigation toggle
- assets/: museum photo and three provided logos

Deploy to GitHub Pages:
1. Create a GitHub repository and upload the contents of this folder (not the folder itself).
2. Repository Settings > Pages > Deploy from a branch.
3. Select main branch and / (root), then Save.

Image credit reminder:
The museum hero photo was supplied in the conversation. Confirm its photographer/source and permission before public launch. Institutional logos are supplied by the organizer.

This is a starter homepage mockup; registration, news, and contact links are placeholders until real content and URLs are supplied.
